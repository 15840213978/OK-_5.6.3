按实际 FM 逻辑恢复，不再人为定义“总线路”。

正确两级选择：

第一层：左上角图标
→ HistoryDialog
→ 显示顶层 Config / 资源线路
→ 宸龙影视、肥猫、驸马、巧计、OK、王二小、yyy 接口等
→ 这是“总的资源线路选择”

第二层：页面标题文字
→ SiteDialog
→ 只显示“当前 Config 解析出来的 Site / 直线路”
→ 当前是 yyy 时，可显示它自己解析出来的腾讯备、爱奇艺、猎手、袋鼠等
→ 选择后直接切当前直线路

V6.6 改动：
1. 不再把 https://yyy.kanglian.cc.cd/yl-nb-yj.json 人为命名成“总线路”或“永乐线路”。

3. 覆盖安装只清理我们前两版人为写入的“总线路/永乐线路”名称。
4. 用户自己修改过的 Config 名称不动。
5. 电视版标题文字现在可点击，弹出当前 Config 的 SiteDialog。
6. 电视版选择 Site 后自动拉该 Site 首页，并新建 VodActivity，避免旧 Fragment/siteKey 串线。
7. 手机版原本已有“标题 -> SiteDialog”，继续保留并锁定。
8. 左上角图标仍然只负责顶层 Config 切换。
9. V6.5 搜索子源、永久屏蔽、V6.4 外部线路进入、V6.2 流式海报墙全部保留。
10. 修改同时覆盖 main / leanback / mobile，因此 Debug / Release、ARM64 / armeabi-v7a 都生效。
